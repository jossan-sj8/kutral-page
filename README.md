# Kütral · página de servicios

Página estática del clúster **Kütral**, del Instituto de Ciencias de la Ingeniería de la
Universidad de O'Higgins (Campus Rancagua).

- **Un solo archivo:** `index.html`. El logo va incrustado, no tiene dependencias ni necesita internet.
- **Cifras** (declaradas por el equipo del proyecto, 2026): 41 nodos · 1.100+ núcleos · 7 TB de RAM ·
  757 TB de almacenamiento · red InfiniBand de 40 Gb/s.
- **Contacto:** hpc@uoh.cl · seq@uoh.cl
